## 1. Get the files in

<Tabs>
  <Tab title="By URL">
    ```bash
    curl -X POST https://api.monkeygun.com/v1/library/upload -H "Authorization: Bearer $MK_KEY" \
      -d '{ "url": "https://cdn.yourapp.com/shoot/clip-01.mp4", "filename": "clip-01.mp4" }'
    # { "assetId": "778324edbbef508c", ... }
    ```
    Any public https file, or a post on X, YouTube, TikTok or Instagram. 250 MB per file.
  </Tab>
  <Tab title="Google Drive">
    ```bash
    curl -X POST https://api.monkeygun.com/v1/tools/import_drive -H "Authorization: Bearer $MK_KEY" \
      -d '{ "url": "https://drive.google.com/drive/folders/…" }'          # lists files
    curl -X POST https://api.monkeygun.com/v1/tools/import_drive -H "Authorization: Bearer $MK_KEY" \
      -d '{ "url": "https://drive.google.com/drive/folders/…", "all": true }'   # imports them
    ```
    The folder must be shared to anyone with the link.
  </Tab>
  <Tab title="Base64">
    `{ "filename": "clip.mp4", "data": "<base64>" }` on the same upload endpoint.
  </Tab>
</Tabs>

## 2. Index it (once)

```bash
curl -X POST https://api.monkeygun.com/v1/tools/index_footage -H "Authorization: Bearer $MK_KEY" \
  -d '{ "assetIds": ["778324edbbef508c"], "quoteOnly": false }'
```

20 credits per minute of footage. Indexing finds scene cuts, describes every scene, and transcribes the speech, so the director can cut from it by content ("the shot of the crowd", "where she says the price"). `quoteOnly: true` prices it first.

For footage without speech (gameplay, b-roll, events, music), `find_highlights` (5 credits per minute) returns the moments: loudness peaks, cuts, and a one-line look at each, with start and end times.

For talking-head clips, `clean_footage` (10 credits per minute) drops filler words and dead air with clean cut edges, and lands a new clip in the library.

## 3. Cut from it

```bash
curl -X POST https://api.monkeygun.com/v1/videos/from-data -H "Authorization: Bearer $MK_KEY" \
  -d '{ "brief": "A 20-second ad for date night at the venue. Use the crowd shots and the duet; end on the booking CTA.",
        "cta": "Book at micdrop.com", "libraryAssetIds": ["778324edbbef508c", "1025aba083607904"],
        "format": "9:16", "targetSeconds": 20, "images": "library", "brand": { "pack": "bold" } }'
```

`images: "library"` tells the engine to place your files rather than stills or generated images. The director sets `clipRef: { assetId, start, duration }` on scenes to pick the exact seconds. In an authored script you set `clipRef` yourself. An audio file in `libraryAssetIds` becomes the music bed.

## Batches from one shoot

Index once, then call `from-data` once per angle with a different brief. There is nothing to batch server-side; each call is independent and the footage index is reused. A 15-ad campaign from one shoot is 15 calls.

## Your users' footage

In the [embedded studio](/guides/embedded-studio), users drop their own files in the chat and the same indexing runs on your account's credits. Uploads that go straight to a feed should pass through a [brand pass and a review hold](/guides/upload-and-brand-pass).
